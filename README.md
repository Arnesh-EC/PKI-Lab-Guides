# EC Two-Tier PKI Lab Guides

Hands-on quick reference guides for building a **two-tier Microsoft Active Directory Certificate Services (ADCS) PKI hierarchy** from scratch: a standalone **offline root CA**, an enterprise **issuing CA**, an **OCSP** Online Responder, and HTTP/LDAP **CRL + AIA** distribution — on Windows Server 2025 VMs with a Windows 11 client.

Please visit the following link to access the guides: <https://arnesh-ec.github.io/PKI-Lab-Guides/>
